# JavaScript HKR – Portfolio Website

## Project Description

This repository contains my portfolio website for the JavaScript for Web Development course at Kristianstad University.
https://hkr.instructure.com/courses/9445/assignments/112924 

The project started in Lab 1 with HTML and CSS. 
In Lab 2, I am adding JavaScript to make the website interactive based on the instructions in the above link.

## My Target Grade

Grade 4.

## Lab 1 Features

- About Me page with personal information and skills
- My Trips page with travel photos
- My Pet page
- Responsive layout using HTML and CSS

## Lab 2 Features

### Feedback Form

I created a feedback form with the following fields:

- Full Name
- Email
- Topic of Interest
- Comments
- Website (optional)

The form currently uses JavaScript to validate the input fields and display error messages.

### Planned Features

- Live character counter for Comments
- Success message and form reset
- Interactive skills showcase
- Filtering and sorting skills

## Tech Stack

- HTML
- CSS
- JavaScript
- Git and GitHub

## How to Run

1. Clone or download this repository.
2. Open the `lab1-portfolio` folder.
3. Open `index.html` in a web browser.
4. Open `feedback.html` to test the JavaScript feedback form.

No backend or installation is required.
